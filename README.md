# Portfólio — Lúcia Schnomberger

Meu portfólio pessoal, publicado em [luciaschnomberger.vercel.app](https://luciaschnomberger.vercel.app).

## Sobre

Site de página única (single-page) apresentando minha trajetória entre biologia, tradução/legendagem e desenvolvimento de software, os projetos que já construí e os serviços que ofereço.

## Seções

- **Sobre** — minha formação e trajetória
- **Serviços** — desenvolvimento de sites e aplicativos, legendagem, tradução, revisão e localização
- **Projetos de Tecnologia** — aplicativos que desenvolvi:
  - [Orgulho de Ser](https://orgulhodeser.app.br) — rede social e app de relacionamento para o público LGBTQIA+
  - [Organizador Pessoal](https://meuorganizadorpessoal.vercel.app) — listas, receitas e controle de consultas/exames
  - [Super Anck](https://github.com/luciaschnomberger/super-anck) — jogo de plataforma em Python
- **Tradução e Legendagem** — títulos em que trabalhei
- **Formação** — trajetória acadêmica
- **Contato**

## Tecnologias

- HTML, CSS e JavaScript puro, em um único arquivo (`index.html`)
- Sem build step, sem dependências, sem framework
- Publicado na Vercel, com deploy automático a cada push neste repositório

## Como rodar localmente

Como é um arquivo único sem dependências, basta abrir o `index.html` direto no navegador, ou servir a pasta com qualquer servidor estático simples:

```
python -m http.server
```
